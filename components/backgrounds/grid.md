# Grid Background

Анимированная сетка, вдохновлённая cult-ui Flickering Grid.

## Использование

```html
<div class="grid-bg grid-bg-small grid-bg-colored">
  <div class="content">Контент</div>
</div>
```

## Варианты

- `grid-bg-small` — мелкая сетка (25px)
- `grid-bg-large` — крупная сетка (100px)
- `grid-bg-colored` — цветная сетка

## CSS-переменные

- `--grid-color` — цвет линий
- `--grid-size` — размер ячейки
- `--bg` — цвет фона
