# Particles Background

Частицы на фоне, вдохновлённые cult-ui Particles.

## Использование

```html
<div class="particles particles-dense particles-colored">
  <div class="content">Контент</div>
</div>
```

## Варианты

- `particles-dense` — больше частиц
- `particles-colored` — цветные частицы (использует `--accent`)

## CSS-переменные

- `--particle-color` — цвет частиц
- `--bg` — цвет фона
