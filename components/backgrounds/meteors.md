# Meteors Background

Падающие метеоры, вдохновлённые cult-ui Meteors.

## Использование

```html
<div class="meteors meteors-slow">
  <div class="content">Контент</div>
</div>
```

## Варианты

- `meteors-slow` — медленные метеоры (15s)
- `meteors-fast` — быстрые метеоры (4s)

## CSS-переменные

- `--meteor-color` — цвет метеоров
- `--bg` — цвет фона
