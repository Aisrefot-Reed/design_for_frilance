# Number Ticker

Бегущие числа, вдохновлённые cult-ui Number Ticker.

## Использование

```html
<h1>Нам доверяют <span class="number-ticker">1234</span> клиентов</h1>
```

## Варианты

- `number-ticker-large` — крупный текст
- `number-ticker-small` — мелкий текст

## Принципы

- Только CSS, без JS
- Число статичное (анимация только курсора)
