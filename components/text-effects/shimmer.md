# Shimmer Text

Переливающийся текст, вдохновлённый cult-ui Shimmer Text.

## Использование

```html
<h1><span class="shimmer">Переливающийся текст</span></h1>
```

## Варианты

- `shimmer-slow` — медленное переливание (5s)
- `shimmer-fast` — быстрое переливание (1.5s)
- `shimmer-gold` — золотой цвет
- `shimmer-silver` — серебряный цвет

## CSS-переменные

- `--shimmer-base` — базовый цвет
- `--shimmer-highlight` — цвет блика
