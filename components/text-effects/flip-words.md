# Flip Words

Переворачивающиеся слова, вдохновлённые cult-ui Flip Words.

## Использование

```html
<h1>Мы делаем <span class="flip-words">
  <span class="word">сайты</span>
  <span class="word">дизайн</span>
  <span class="word">бренды</span>
</span></h1>
```

## Варианты

- `flip-words-slow` — медленная смена (12s)
- `flip-words-fast` — быстрая смена (6s)

## Принципы

- Ровно 3 слова
- Только CSS, без JS
- `prefers-reduced-motion` отключает анимацию
