# Typewriter

Эффект печатной машинки, вдохновлённый cult-ui Typewriter.

## Использование

```html
<h1><span class="typewriter">Текст для печати</span></h1>
```

## Варианты

- `typewriter-slow` — медленная печать (5s)
- `typewriter-fast` — быстрая печать (1.5s)
- `typewriter-no-caret` — без курсора

## Принципы

- Только CSS, без JS
- Текст должен быть в `inline-block` элементе
- `prefers-reduced-motion` отключает анимацию
