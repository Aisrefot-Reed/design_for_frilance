# Tilt Card

Карточка с наклоном при наведении, вдохновлённая cult-ui Tilt.

## Использование

```html
<div class="tilt">
  <h3>Заголовок</h3>
  <p>Описание</p>
</div>
```

## Варианты

- `tilt-dark` — тёмная
- `tilt-accent` — акцентная
- `tilt-strong` — сильный наклон
- `tilt-weak` — слабый наклон

## Принципы

- Наклон следует за курсором (требует JS для `--rx` и `--ry`)
- Без JS — статичный наклон
- `prefers-reduced-motion` отключает анимацию
