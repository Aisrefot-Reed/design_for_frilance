# Glare Card

Карточка с бликом, вдохновлённая cult-ui Glare Card.

## Использование

```html
<div class="glare">
  <h3>Заголовок</h3>
  <p>Описание</p>
</div>
```

## Варианты

- `glare-dark` — тёмная
- `glare-accent` — акцентная

## Принципы

- Только CSS, без JS
- Блик проходит при наведении
- `prefers-reduced-motion` отключает анимацию
