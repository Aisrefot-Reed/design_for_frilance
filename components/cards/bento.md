# Bento Grid

Адаптивная сетка bento, вдохновлённая cult-ui Bento Grid.

## Использование

```html
<div class="bento">
  <div class="bento-item">Карточка</div>
  <div class="bento-item bento-item-wide">Широкая</div>
  <div class="bento-item bento-item-large">Большая</div>
</div>
```

## Размеры

- `bento-item-wide` — 2 колонки
- `bento-item-tall` — 2 строки
- `bento-item-large` — 2×2

## Варианты

- `bento-item-dark` — тёмная
- `bento-item-accent` — акцентная
- `bento-item-gradient` — градиентная

## Адаптивность

- Мобильный: 1 колонка
- Планшет (700px+): 2 колонки
- Десктоп (1000px+): 4 колонки
