# Input

Стилизованные поля ввода, вдохновлённые shadcn/ui Input.

## Использование

```html
<input type="email" class="form-input" placeholder="email@example.com">
```

## Варианты

- `form-input-error` — ошибка
- `form-input-success` — успех
- `form-input-sm` — маленький
- `form-input-lg` — большой

## Принципы

- `transition` на `border-color` и `box-shadow`
- `prefers-reduced-motion` отключает анимацию
