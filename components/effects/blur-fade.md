# Blur Fade

Появление с размытием, вдохновлённое cult-ui Blur Fade.

## Использование

```html
<div class="blur-fade">Контент</div>
```

## Варианты

- `blur-fade-slow` — медленное (1.5s)
- `blur-fade-fast` — быстрое (0.3s)
- `blur-fade-left` — слева
- `blur-fade-right` — справа
- `blur-fade-scale` — масштабирование
