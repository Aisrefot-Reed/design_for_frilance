# Parallax

Параллакс эффект, вдохновлённый cult-ui Parallax Grid.

## Использование

```html
<div class="parallax">
  <div class="parallax-bg"></div>
  <div class="parallax-content">Контент</div>
</div>
```

## Варианты

- `parallax-fixed` — фиксированный фон
- `parallax-slow` — медленный параллакс

## Принципы

- Только CSS, без JS (базовый вариант)
- Для динамического параллакса требуется JS
- `prefers-reduced-motion` отключает анимацию
