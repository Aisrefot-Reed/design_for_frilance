# Sticky Scroll

Липкий скролл, вдохновлённый cult-ui Sticky Scroll.

## Использование

```html
<div class="sticky-scroll">
  <div class="sticky-scroll-aside">
    <h2>Заголовок</h2>
    <p>Описание</p>
  </div>
  <div class="sticky-scroll-steps">
    <div class="sticky-step">
      <div class="sticky-step-num">1</div>
      <h3>Шаг</h3>
      <p>Описание шага</p>
    </div>
  </div>
</div>
```

## Принципы

- Только CSS, `position: sticky` без JS
- На мобильном колонки складываются, sticky отключается
- Хорошо работает для «как мы работаем», «этапы», «процесс»

## Когда использовать

Подходит бизнесу с процессом: автосервис, клиника, мастерская, юридические услуги.
