# Testimonial Section

Секция отзывов, вдохновлённая shadcnblocks Testimonial.

## Использование

```html
<section class="testimonials">
  <div class="testimonials-container">
    <div class="testimonials-header">
      <h2>Отзывы</h2>
    </div>
    <div class="testimonials-grid">
      <div class="testimonial-card">...</div>
    </div>
  </div>
</section>
```

## Структура карточки

- `testimonial-stars` — звёзды
- `testimonial-text` — текст отзыва
- `testimonial-author` — автор (аватар, имя, роль)

## Адаптивность

- Мобильный: 1 колонка
- Планшет: 2 колонки
- Десктоп: 3 колонки
