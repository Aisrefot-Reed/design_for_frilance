# Logo Cloud

Облако логотипов, вдохновлённое cult-ui Logo Cloud.

## Использование

```html
<section class="logo-cloud">
  <div class="logo-cloud-inner">
    <p class="logo-cloud-title">Нам доверяют</p>
    <div class="logo-cloud-grid">
      <div class="logo-cloud-item">Партнёр</div>
    </div>
  </div>
</section>
```

## Варианты

- `logo-cloud-plain` — без плашек
- `logo-cloud-dark` — тёмная тема

## Адаптивность

- Мобильный: 2 колонки
- Планшет+: 4 колонки
